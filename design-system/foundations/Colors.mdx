# Cores

Uma paleta pequena: o verde escuro aparece pouco (item ativo, ícones de ação) e o menta faz os destaques. Os componentes nunca usam os primitivos diretamente, só as cores semânticas.

## Contraste (WCAG AA)

Texto normal exige 4,5:1; texto grande e ícones exigem 3:1. A combinação de `action-primary` sobre `bg-highlight` só vale para ícones e texto a partir de 24px.
